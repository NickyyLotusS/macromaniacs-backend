# Contrato com a equipe de infraestrutura

Registrar neste documento as definicoes compartilhadas entre backend e infra:

- ambientes de desenvolvimento, homologacao e producao;
- banco de dados e versao;
- storage para imagens e PDFs;
- fila ou mecanismo para jobs assincronos;
- secrets e variaveis de ambiente;
- CI/CD e estrategia de rollback;
- logs, metricas, alertas e health checks;
- dominio, HTTPS, rede e politica de CORS;
- responsabilidade pela execucao de migrations.
